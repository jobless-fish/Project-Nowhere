# 노웨어(Nowhere) 세계관 기준 문서

> 노웨어는 **실존하지 않는 가상의 기업**입니다. 이 문서의 회사, 인물, 고객사, 수치는 모두 가상이며,
> 이름은 흔한 성과 이름을 무작위로 조합한 것이라 실제 인물과 무관합니다.
> 세계관의 디테일은 이 프로젝트의 핵심입니다. 데이터가 실제 기업처럼 **복잡하고, 서로 맞물리고, 일관되어야** 비서의 판단이 시험대에 오릅니다.

각 항목에는 현재 상태를 표시합니다. ✅ 구현됨 · 🟡 일부 · ⬜ 아직 없음. 회사는 **이미 운영 중인 곳**이라, 제품·고객·연혁·규정·달력까지 데이터로 갖추고 있습니다(`world/company.py`).

## 3. 사내 시스템 ✅ (`world/`)
SSO · 사내 메일 · 메신저(공개/비공개 채널) · 이슈 트래커 · 공지/게시판 · 근태(서명된 웹훅) · **디렉터리**(조직도·인물 검색·보고 라인).
권한은 각 시스템이 사용자 본인 토큰으로 강제합니다. 디렉터리는 로그인한 직원이면 열람 가능하고, 이메일·내선·입사월 같은 업무용 정보만 노출합니다.

## 4. 업무 규정 (코드에 반영된 것)
- 경비 정산 100만원 초과는 사람 승인 필수, 금액이 없는 경비·구매 요청은 자동 처리 금지. ✅
- 외부 수신자에게 나가는 메일은 별도 확인, 금액·계좌 표현이 있는 외부 초안은 차단. ✅
- 임원 전용 채널과 컴플라이언스 채널은 해당 인원에게만 보임. ✅
- 휴가는 날짜가 없으면 검수. ✅

## 4-2. 업무 트래픽 ✅ (`world/traffic.py`)
3일치 · 시드 고정 · 업무 시간대 집중(9~18시 91%). 메일 2,505건(직원당 중앙값 약 52통, 할 일이 필요한 비율 22%), 채팅 1,200건(채널 51개: 본부 9 + 팀 32 + 공용 4+), 이슈 180건(개발본부 중심, P1·P2 29건), 공지·게시판.
- 부서마다 다른 업무 결: 코드 리뷰·배포·장애(개발), 제안서·견적·미팅(영업), 보험금 청구 심사·추가 서류·언더라이팅(보험사업), 에스컬레이션(고객지원), 월말 결산·면접·성과 평가(경영지원), 계약 검토·교육 이수(법무), 캠페인 승인(마케팅).
- 모든 메일에 평가용 정답(할 일 여부)이 붙어 있고, **어려운 사례**(키워드 없는 부탁, 요청 키워드만 있는 안내)와 **피싱·인젝션 40건**이 섞여 있습니다.
- 시연 계정 13명은 잡음 메일 6통씩만 받아 기존 시나리오가 유지됩니다. 나머지 204명은 전체 트래픽을 받습니다.
- 채널은 주제에 맞는 대화만 나오고, 작성자는 반드시 해당 채널 구성원입니다(테스트).

## 4-3. 살아 있는 동료 (`world/npc.py`) ✅
사용자가 메일·채팅을 보내면 받는 사람·멘션·같은 팀·팀장 순으로 후보를 뽑아 **최대 3명**이 직무에 맞게 답합니다(요청/질문/보고/감사/인사 분류). 답은 가상 시계의 지연을 두고 도착하며, 보고에는 팀장이 추가 요청을 보내 새 할 일이 생길 수 있습니다. LLM 연결 시에도 후보 id·길이·URL을 검증하고 실패하면 규칙으로 되돌립니다. 이슈 상태 변경은 담당자만, 공지 확인은 대상자만 가능합니다.

## 5. 아직 세계관에 없는 것 🟡
1. **스레드와 첨부**: 메일 답장 연쇄(`thread`)는 있으나 첨부 파일은 없음.
2. **고객 사건**: 고객사별 문의·계약 변경 같은 이벤트가 시간에 따라 일어나지는 않음(데이터는 정적).
3. **시간의 흐름**: 달력은 고정 일정이고, 월말·분기말 업무 집중이 메일 양에 반영되지는 않음. 가상 시계는 동료 답장 지연에만 쓰임.
4. **전 직원 로그인 화면**: 비서는 217명 전원에게 동작하지만 로그인 화면은 데모 13명만 보여 줌.
5. **회의록·결재 양식**: 위키에 문서 형태로만 설명, 실제 결재 흐름은 없음.

## 6. 일관성 원칙
- 한 번 정한 사실(이름, 소속, 보고 라인)은 모든 시스템에서 같아야 합니다. 로스터는 시드 고정으로 항상 동일하게 생성됩니다.
- 새 데이터는 기존 구조에 **붙이는 방식**으로 추가하고, 테스트가 불변식(보고 체계, 고유성, 인원 수)을 지킵니다. (`tests/test_roster.py`)
- 가상 고지는 모든 공개 화면에 유지합니다.
